# Runtime dependencies for the public image (application/apps/api/Dockerfile.public).
#
# Kept separate from requirements.txt, which is the local development set, for
# two reasons:
#
#   1. requirements.txt pins the Paperclip SDK as a direct URL:
#          gxl-paperclip @ https://paperclip.gxl.ai/paperclip.whl
#      pip rejects that URL because `paperclip.whl` is not a PEP 427 wheel
#      filename — a wheel must be named {name}-{version}-{python}-{abi}-{platform}.whl.
#      It fails with "paperclip.whl is not a valid wheel filename" and takes the
#      whole build down with it. The image installs that same wheel a step later,
#      via scripts/install_paperclip.py, which renames it correctly first.
#
#   2. Test-only packages do not belong in a runtime image.
#
# pipeline_core is installed separately, earlier in the Dockerfile.
